#  Road Traffic Detection Using YOLOv8

##  Project Overview

Road Traffic Detection is a Computer Vision project that uses the YOLOv8 object detection model to detect and identify different objects on roads.
The system analyzes road traffic images and videos to detect traffic-related objects such as vehicles, buses, bicycles, motorcycles, traffic lights, and other road objects.
This project demonstrates how Deep Learning and Object Detection can be used to develop intelligent traffic monitoring systems.

## 🛠️ Technologies Used

- Python
- YOLOv8
- Computer Vision
- Deep Learning
- OpenCV
- Roboflow
- Google Colab
- NumPy
- Matplotlib

##  Dataset

The dataset was collected using Roboflow.

It contains annotated road traffic images for training, validation, and testing the YOLOv8 object detection model.

##  Detection Classes

The model is designed to detect road-related objects, including: 7 classes

- Bicycles
- Buses
- Crosswalks
- Fire Hydrants
- Motorcycles
- Traffic Lights
- Vehicles

##  Project Workflow

1. Dataset Collection using Roboflow.
2. Data Annotation and Preprocessing.
3. Dataset Splitting into Training, Validation, and Testing.
4. YOLOv8 Model Configuration.
5. Model Training and Validation.
6. Model Performance Evaluation.
7. Object Detection on Images and Videos.
8. Prediction Visualization using Bounding Boxes.

##  Model Evaluation

The model can be evaluated using the following metrics:

- Precision
- Recall
- mAP@50
- mAP@50-95
- Confusion Matrix
